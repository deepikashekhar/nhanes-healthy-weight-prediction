# NHANES 2017–2018 Source Data

This study uses publicly available data from the National Health and Nutrition Examination Survey (NHANES) 2017–2018 conducted by the National Center for Health Statistics (NCHS), Centers for Disease Control and Prevention (CDC).

The following public-use datasets were used in this study:

| Dataset | Description |
|----------|-------------|
| DEMO_J | Demographic Variables and Sample Weights |
| BMX_J | Body Measures |
| DPQ_J | Depression Screener (PHQ-9) |
| PAQ_J | Physical Activity |
| SLQ_J | Sleep Disorders |
| DR1TOT_J | Dietary Interview – Total Nutrient Intakes (Day 1) |
| WHQ_J | Weight History |

Original NHANES data are publicly available from the CDC:

https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017
