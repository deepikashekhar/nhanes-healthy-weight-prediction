# Assessing the Incremental Predictive Value of Depressive Symptom Severity in Predicting Healthy Weight Status Using Machine Learning and Explainable Artificial Intelligence

## Overview

This repository contains the code, datasets, and supporting materials for my DBA Data Analytics Capstone at Walsh College.

## Data Source

The study uses publicly available NHANES 2017–2018 data published by the Centers for Disease Control and Prevention (CDC).

## Repository Contents

- notebooks – Python notebook used for data preparation
- data – datasets used in the study
- outputs – summary files generated during preprocessing
- figures – figures used in the synopsis and dissertation
